# Enterprise SOC Home Lab
My home lab! Focused on Active Directory, security monitoring, SIEM implementation, detection engineering, threat hunting, incident response, and security automation through simulated enterprise environments.

**Status:** In Progress

## Overview

This project documents my journey building an enterprise my home lab to gain hands-on experience in security operations, detection engineering, and incident response.

## Lab Environment

| System | Purpose |
|---|---|
| VMware Workstation | Virtualization |
| Windows Server 2019 | Domain Controller |
| Windows 11 Pro | Client Endpoint |
| Kali Linux | Security Testing |
| Wazuh  | SIEM |
| Sysmon  | Endpoint Monitoring |
